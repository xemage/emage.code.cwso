# Project Planning — Reference Templates

Reusable templates referenced by the `project-planning` skill.

## Available templates

| Template | Purpose |
|---|---|
| [`work-breakdown-structure.md`](./work-breakdown-structure.md) | Decompose a feature into deliverables, tasks, and estimates |
| [`milestone-roadmap.md`](./milestone-roadmap.md) | Quarterly / monthly milestone view |
| [`sprint-plan.md`](./sprint-plan.md) | Single sprint plan with capacity, goals, and stories |

> Templates are intentionally minimal Markdown skeletons. Copy into
> `docs/plans/` (or your project's planning location) and fill in.
